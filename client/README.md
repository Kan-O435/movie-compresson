# Discord Video Compressor - Client

FastAPIの動画圧縮ジョブAPIを操作するNext.js（App Router, TypeScript）クライアント。

セットアップ・起動方法・操作手順・API一覧・制約については、リポジトリルートの [README.md](../README.md) の「クライアント（Next.js）」セクションを参照してください。

## クイックスタート

```bash
npm install
cp .env.local.example .env.local
npm run dev
```

## スクリプト

```bash
npm run dev     # 開発サーバー起動
npm run build   # 本番ビルド
npm run lint    # ESLint
npm test        # vitestによるユーティリティのユニットテスト
```
